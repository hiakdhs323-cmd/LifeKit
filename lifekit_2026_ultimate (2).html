APK 개발자 연동 가이드

1. CORS 제한 해결 방법

안드로이드 앱 내부 웹뷰(WebView)에서 외부 API 호출 시 CORS 차단이 발생할 수 있습니다.

webSettings.setAllowUniversalAccessFromFileURLs(true);

2. HTTP (Cleartext) 차단 해결

안드로이드 9 이상에서는 암호화되지 않은 HTTP 통신이 기본 차단됩니다. (예: http://ianfette.org 검사 시)

<application
    android:usesCleartextTraffic="true"
    ... >
